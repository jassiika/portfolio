# Personal Portfolio Website

A personal portfolio website built using **HTML5** and **CSS3** to showcase my profile, skills, education, and projects.

## About

This portfolio represents my journey as a Computer Science Engineering student and aspiring Frontend Developer. The website features a clean dark-themed design with a responsive layout and organized sections for personal and professional information.

## Features

* Responsive design for different screen sizes
* Professional profile section
* Skills showcase with technology icons
* Education timeline
* Project portfolio section
* Social media and contact links
* Modern dark UI with smooth hover effects

## Technologies Used

* HTML5
* CSS3
* CSS Grid
* Flexbox
* Responsive Web Design
